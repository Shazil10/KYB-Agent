# n8n Workflow

This folder is for the exported n8n workflow JSON used in the demo.

Recommended export filename:

`ubo-hunter-workflow.json`

## Expected workflow stages

1. Webhook trigger from Lovable
2. MiniMax extraction request
3. Ownership classifier
4. Registry lookup / recursive loop
5. Risk scoring
6. Final JSON formatter
7. Optional Crossmint trigger or frontend callback

If you export the live workflow from n8n before judging, place it in this folder.
